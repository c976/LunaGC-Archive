# Co-Op Mode

Co-Op Mode is unlocked after reaching Adventure Rank 16 and completing Archon Quest Prologue: Act I - The Outlander Who Caught the Wind. In Co-Op Mode, a Party of up to four Travelers can adventure simultaneously to take on Domains, participate in certain Events, and explore the open world of Teyvat together.

The Co-Op Mode Menu lists currently online players and allows searching by UID. The list displays the player's avatar, name, Adventure Rank, profile signature, the number of people in their world, and their status.

Players can set their World Permissions to Reject Join Requests, Allow Direct Join, and Join After Approval.

## Rules and Restrictions

| Feature                               | Status | Notes                                                                                                                                                                                                                                       |
| ------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Joining another world                 |        | Players can join worlds only when the host's World Level and Adventure Rank range are less than or equal to their own. Players at World Level 8 and 9 can freely enter each other's worlds.                                                 |
| Joining a Serenitea Pot               |        | Friends can join each other's Serenitea Pot regardless of World Level or Adventure Rank.                                                                                                                                                    |
| Quests that disable Co-Op             |        | Some Archon, Story, World, and Event Quests manipulate the world and disable Co-Op Mode, even when they are not the active quest. This also prevents access to the player's own Serenitea Pot. Co-Op may be re-enabled between quest steps. |
| Activities requiring the Co-Op screen |        | These cannot be started while Co-Op is disabled, even if they can otherwise be played solo.                                                                                                                                                 |
| Party size and characters             |        | With two players, each chooses two characters. With three, the host chooses two and each other player chooses one. With four, each player chooses one. Players can change fielded characters in Party Setup while out of combat.            |
| Duplicate characters                  |        | Players can use the same character outside Domains, but not within Domains. Both male and female Traveler can be in a Domain party at the same time.                                                                                        |
| Enemy scaling                         |        | Enemies and their variation types scale with the number of players in the world.                                                                                                                                                            |

# Friend

[Friends](https://genshin-impact.fandom.com/wiki/Friend) are players that are added to the Friends List in Genshin Impact. Adding friends makes it easier to check their Player Profile and to join them for Co-Op sessions. Private chat messages can be sent to friends. Friends can also be assigned a nickname for easier recognition. In addition, friends can receive requests to visit their Serenitea Pot. Unlocking the friends list requires Adventure Rank 2.

# Chat

[Chat :cat:](https://genshin-impact.fandom.com/wiki/Chat) is a Game System that allows players to communicate with one another using text and certain emojis. To chat with another player, they must first be added as a Friend.

In Co-Op Mode, a chat for the team is automatically created. This is also the case while inside a Serenitea Pot. Co-Op Mode's Chat also displays a message when players enter and leave the world.
